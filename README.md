# 🎯 Jogo de Adivinhação (Guessing Game)

Um projeto simples e divertido de **Jogo de Adivinhação** desenvolvido com **HTML5, CSS3 e JavaScript**. O objetivo do jogo é tentar adivinhar um número secreto gerado aleatoriamente entre **1 e 100**.

https://gabi-oli.github.io/jogo-de-adivinha-o-/
---

## 🎨 Apresentação Visual

O projeto conta com uma interface intuitiva e responsiva, com visual moderno e cores vibrantes:
* **Fundo principal:** Roxo `#5B3DF5`
* **Cartão central:** Amarelo `#FFD95A`
* **Botão interativo:** Azul `#0047FF`

---

## 🚀 Funcionalidades

- [x] Input para o jogador digitar o palpite (entre 1 e 100).
- [x] Validação do palpite e feedback visual/dicas (se o número correto é maior ou menor).
- [x] Interface centralizada e estilizada com CSS Flexbox.
- [x] Design limpo com bordas arredondadas e efeito de hover no botão.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica da página.
* **CSS3:** Estilização, layout centralizado com Flexbox e paleta de cores.
* **JavaScript:** Lógica do jogo e manipulação de eventos DOM.
